# Sistema de Ventas e Inventario de Hardware y Tecnología

## Descripción

Este proyecto consiste en el desarrollo de un sistema de ventas e inventario orientado a un negocio dedicado a la comercialización de computadoras, componentes de hardware, periféricos y accesorios tecnológicos.

El sistema permitirá optimizar la gestión de ventas y el control estricto del inventario, facilitando el registro, seguimiento y consulta de la información de las piezas y equipos disponibles.

---

## Objetivo

Desarrollar un sistema que permita gestionar de manera eficiente las ventas y el inventario de un negocio especializado en equipo de cómputo y tecnología.

---

## Funcionalidades principales

El sistema contará con funcionalidades como:

- Registro y gestión de productos (ensambles, piezas individuales y periféricos).
- Control de inventario.
- Registro de ventas.
- Actualización automática del stock.
- Gestión de clientes.
- Gestión de proveedores.
- Consulta de componentes y equipos disponibles.
- Generación de reportes de ventas e inventario.
- Alertas de productos con stock bajo.
- Registro y seguimiento de artículos mediante Número de Serie (S/N) para control de garantías.

---

## Tecnologías utilizadas

El proyecto será desarrollado utilizando diferentes tecnologías, entre ellas:

- Java
- Base de datos SQL
- Git
- GitHub

Otras tecnologías serán agregadas durante el desarrollo del proyecto.
